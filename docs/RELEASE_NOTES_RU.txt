v0.7.12 — проверенный пользовательский бинарник без пересборки

- Плавные оси MOZA, штатный тормоз/реверс, автомат/механика через настройки игры.
- Сохранение намерения включения после пауз, катсцен и смены игрового объекта;
  ранее активная сессия восстанавливается без нового ожидания нейтрали.
- Исправлен поиск автомобиля после взрывов: обход активного count вместо
  ошибочного поиска нулевого конца в старом хвосте контейнера.
- Крестовина разрешена в наблюдаемом состоянии окна «Принять / отклонить»;
  оси в таком состоянии не разрешаются. Блокировки неизвестных состояний сохранены.
- Функциональность протестирована автором проекта на нескольких гонках/погонях.
- Лаунчер/маркер сохранены; обновлены манифест и статическая проверка установки.
- Публичный пакет без MOZA_SDK.dll (разрешение ожидается) и без старого dinput8.dll
  (происхождение конкретной старой копии не подтверждено).
- Внешние зависимости устанавливаются отдельно официально. Новые их версии
  не считаются автоматически проверенными.
- Diagnostics по умолчанию0, остальные параметры рабочего INI сохранены.
